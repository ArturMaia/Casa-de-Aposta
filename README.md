# Gerador de Números de Loteria

Projeto em Python com interface gráfica usando Tkinter, que permite ao usuário gerar combinações aleatórias para diversos tipos de loterias brasileiras.

## Funcionalidades

- Geração de números para:
  - Mega-Sena
  - Quina
  - Lotofácil
  - Viva Sorte
  - Dupla Sena (dois sorteios)
  - Timemania (com time do coração)
  - Loteca
- Interface amigável com seleção via menu suspenso
- Visual limpo com design responsivo para telas verticais e horizontais
- Resultados exibidos em caixa de texto expansível

## Tecnologias Utilizadas

- Python 3
- Tkinter (interface gráfica)
- ttk (estilização de componentes)
